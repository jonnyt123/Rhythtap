## One-line pitch

RhythmTap is a fast, mobile-first three-lane browser rhythm game with combo scoring, cloud progression, custom chart imports, and real-time two-player score battles.

## Short store description

Tap circular notes across three lanes, chase Perfect hits, build combos, earn XP, and push your high scores across Easy, Normal, and Hard charts. RhythmTap runs directly in mobile and desktop browsers, supports cloud progression through RhythmTap ID, includes private real-time 1v1 score battles, and can import Phoenix-style .tap charts with local audio.

## Feature bullets

- Instant browser play on mobile and desktop
- Easy, Normal, and Hard difficulty charts
- Perfect / Great / Good / Miss timing judgments
- Combo multiplier and persistent high scores
- RhythmTap ID profiles, XP, levels, achievements, and cloud progression
- Real-time private two-player rooms with server-verified results
- Phoenix-style .tap chart import with local audio stored on-device
- Mobile performance controls and offline caching for played audio

## CrazyGames submission summary

**Game name:** RhythmTap

**Short description:** A fast three-lane browser rhythm game with touch-first controls, multiple difficulties, combo scoring, progression, custom chart imports, and real-time two-player score battles.

**Controls:**
- Mobile: tap the three circular pads; hold for hold notes.
- Desktop: D = left lane, F = center lane, J = right lane, Escape = pause.

**Core loop:** Pick a song and difficulty, hit notes to the beat, maintain a combo multiplier, finish the chart, improve the score, earn eligible progression, and replay or challenge another player.
